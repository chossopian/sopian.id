## Overview

FIMS (FIWA Integration Management System) is an internal platform built from the ground up to digitize and streamline academic and administrative operations at Fitrah Islamic World Academy. It replaces fragmented manual processes — spreadsheets, paper forms, and disconnected tools — with a unified, automated system.

## What It Does

- **Academic Operations** — Manages lesson roster scheduling, student transfer processing, and end-of-term report card generation and distribution.
- **User & Access Management** — Handles user provisioning, account deactivation, and Role-Based Access Control (RBAC) to keep system access secure across departments.
- **Workflow Automation** — Integrates with **n8n** and the **Evolution API** (WhatsApp) to automate routine notifications and administrative messaging, removing manual follow-up work.
- **IT Administration Layer** — Extends into managing the school's Google Workspace Admin Console: account lifecycles, role assignments, and Chromebook device policy & licensing.

## Technical Approach

The system was engineered end-to-end using a low-code foundation (**AppSheet**) paired with a custom **MySQL** backend for data logic, allowing rapid iteration on features as organizational needs evolved. Beyond the core app, custom automation was layered on top using **Google Apps Script** and **n8n** to connect disparate tools (messaging, spreadsheets, admin consoles) into one coherent workflow.

## Key Technical Highlights

- Designed and implemented database schema and business logic to support evolving academic workflows.
- Built and maintained Role-Based Access Control (RBAC) for secure, department-level data access.
- Automated cross-platform notifications via n8n + Evolution API (WhatsApp) integration.
- Ongoing debugging, feature development, and system reliability maintenance for a live, actively-used platform.
